# hidara releases

Windows installers and the auto-update feed for **hidara**, a desktop music player designed and built by **NiMAA** for [ZynTECH](https://flinnzee.github.io/Zyntech/).

**Website: https://flinnzee.github.io/hidara-releases/**

hidara was called sonara until version 3.0. Installed copies of sonara update to hidara by themselves and keep their library.

## Install

1. Download `hidara-<version>-setup.exe` from the [latest release](../../releases/latest) and run it. Prefer no installer? Unzip `hidara-<version>-portable.zip` anywhere and run `hidara.exe` (it doesn't update itself).
2. On first launch hidara sets up its backend (about a minute), then you can search and play. Nothing else to install: Python comes inside the installer.

Installed copies check this feed and update themselves; a "Restart to update" button appears when a new version is ready.

This repository only hosts release files. The source code is private.
