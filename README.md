# sonara releases

Windows installers and the auto-update feed for **sonara**, a desktop music player designed and built by **NiMAA** for [ZynTECH](https://flinnzee.github.io/Zyntech/).

**Website: https://flinnzee.github.io/sonara-releases/**

## Install

1. Download `sonara-<version>-setup.exe` from the [latest release](../../releases/latest) and run it.
2. On first launch sonara sets up its backend (about a minute), then you can search and play. Nothing else to install: Python comes inside the installer.

Installed copies check this feed and update themselves; a "Restart to update" button appears when a new version is ready.

This repository only hosts release files. The source code is private.
